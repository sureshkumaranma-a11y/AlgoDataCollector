# Algo Data Collector MVP

Android MVP for recording NIFTY/SENSEX/options observations for backtesting.

Fields include timestamp, instrument, timeframe, OHLC, volume, option premium, velocity, acceleration and notes.

Build with JDK 17 and Gradle 8.7+:
`gradle assembleDebug`

APK:
`app/build/outputs/apk/debug/app-debug.apk`
